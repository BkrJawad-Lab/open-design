# صِلة دوائي · SILA IQ — Interactive Web Slide Deck

عرض تقديمي تفاعلي (12 شريحة) للخطة التسويقية والاستراتيجية للنمو — صِلة دوائي (SILA IQ)،
بُنٍي على نمط نظام **Open Design · html-ppt** (`design-templates/html-ppt`):
بنية `.deck > .slide`، runtime للتنقل، عدّادات مؤشرات (count-up)، وكشف متدرّج (staggered reveals) —
بثيم **Dark Teal / Glassmorphism** مستوحى من هوية صِلة دوائي.

## التشغيل

```bash
# من جذر المستودع:
python3 -m http.server 8321 --bind 0.0.0.0 --directory presentation
# ثم افتح: http://localhost:8321
```

أو افتح `presentation/index.html` مباشرة في المتصفح — الملف مستقل 100% (لا Build step).
يتطلب اتصالاً بالإنترنت لتحميل خطَي Cairo/Tajawal من Google Fonts.

## التحكم

| الزر | الفعل |
|---|---|
| `←` / `Space` / `Enter` / `↓` / `PageDown` | الشريحة التالية |
| `→` / `↑` / `PageUp` / `Backspace` | الشريحة السابقة |
| `1` … `9`, `0` | قفز مباشر للشريحة (10) |
| `Home` / `End` | البداية / النهاية |
| `G` | نظرة عامة (شبكة مصغّرات — انقر للانتقال) |
| `F` | ملء الشاشة |
| `P` | طباعة / حفظ PDF |
| `H` | إظهار/إخفاء شريط التلميحات |
| سحب على اللمس | تنقّل أمامي/خلفي |

توجد أزرار شاشة مطابقة (نظرة / السابق / التالي / ملء / طباعة) + شريط تقدم علوي
+ مسار نقاط جانبي + عدّاد صفحات. التوجيه RTL كامل والخطوط: **Cairo** (عناوين) / **Tajawal** (نصوص).

## الطباعة / PDF عالي الجودة

اضغط `P` (أو زر الطباعة) واختر **Save as PDF**:
- كل شريحة تصبح صفحة **A4 أفقية** مستقلة.
- الخلفيات تُطبَّع تلقائياً (`print-color-adjust: exact`) — إن ظهر شيء باهت فعّل
  خيار **Background graphics** في حوار الطباعة.
- روابط مباشرة إلى شريحة بعينها: `index.html#s5`.

## نسخة PowerPoint التنفيذية (.pptx)

ملف جاهز: **`docs/silla-iq-executive-presentation.pptx`** (14 شريحة، 16:9)

```bash
python3 build_pptx.py   # إعادة التوليد (يتطلب: pip install python-pptx)
```

قواعد التصميم المطبّقة (Executive / Human-Crafted):
- أبعاد 13.333" × 7.5" (EMU 12192000 × 6858000) — 16:9 حقيقي.
- خلفيات Off-White `#F8FAFC`، والغلاف والخاتمة كحلي `#0A192F`.
- لوحة: نصوص `#0F172A` · ثانوي `#64748B` · حدود `#E2E8F0` · تمييز Teal `#0D9488` · ثانوي `#E11D48` / `#F59E0B`.
- خط **Cairo** مضبوط على `a:latin` + `a:ea` + `a:cs` (عبرية معقدة) — وهو خط Google
  فيدرجي، لذا يفتح في Google Slides بنفس الخط تلقائياً.
- RTL كامل: `rtl="1"` على كل فقرة (533/533) و`lang="ar"` على كل run.
- بدون ظلال وبدون تدرجات — بطاقات بيضاء مسطحة بحدود رفيعة `#E2E8F0` وحواف دائرية.
- الجداول جداول PPTX أصلية (No-Grid + تعبئة يدوية) — قابلة للتعديل في Slides.
- تنوع البنى: غلاف Minimal · 3 عمود · مثلث منظومة مرسوم · 5 أعمدة · 2×2 ·
  مصفوفة · 3×2 · خط زمني 4 مراحل · عمودان مقسومان · شبكة قنوات · Big-Number KPIs ·
  صفوف مرقمة · جدول تنفيذ · خاتمة كحلية.

**ملاحظة Google Slides:** افتح الملف عبر Drive → فتح → Google Slides؛ لا حاجة لأي تصدير
أو تحويل. إن ظهر افتقار لحجم خط معين، Cairo موجود في قائمة خطوط Google Slides مباشرة.
