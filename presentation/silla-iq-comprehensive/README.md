# صلة دوائي · Silla Dawaai — الملف الشامل (31 صفحة تفاعلية)

عرض ويب تفاعلي (RTL، عربي) مكوّن من **31 صفحة** يلخّص «الملف الشامل — 50 صفحة»
(تجميع كل الأفكار والخطط والتحليلات من بداية مشروع صلة دوائي)، بأسلوب تنفيذي
خارجي: **خلفية فاتحة / أبيض** وهويتا الثقة والأمان:
`Teal #2C7873 · #0E7C86 · #EBFAF1`.

- المصدر: وثيقة المشروع الشاملة (Red Team + الحلول القديمة والجديدة + اقتصاديات الطلب).
- الهوية: التموضع «نتحقق قبل أن نوصل» · بغداد فقط · R1/R2/R3 · ميزانية 7500$ · 60 يوم إطلاق.
- الخطّ المقصود **Rawasi (رواسي العربي)**؛ لا يتوفر على Google Fonts، لذلك يقع
  الملف تلقائياً على **Tajawal / Cairo** من Google Fonts. لإظهاره برواسي: ضع ملف
  `rawasi.woff2` بجوار `index.html` وأضف `@font-face` في بداية `_head` أو داخل
  `<style>` ثم غيّر `--fd` / `--fb` إلى `'Rawasi'`.

## التشغيل

الملف **مستقل 100%** (لا build step) — افتح `index.html` مباشرة في المتصفح، أو:

```bash
# من جذر المستودع:
python3 -m http.server 8410 --bind 0.0.0.0 --directory presentation/silla-iq-comprehensive
# ثم افتح: http://localhost:8410
```

(يتطلب اتصالاً لتحميل خطَّي Tajawal/Cairo.)

## التحكم

| الزر | الفعل |
|---|---|
| `←` / `Space` / `Enter` / `↓` / `PageDown` | الصفحة التالية |
| `→` / `↑` / `PageUp` / `Backspace` | الصفحة السابقة |
| `1`…`9`, `0` | قفز للصفحة |
| `Home` / `End` | البداية / النهاية |
| `G` | نظرة عامة (شبكة صفحات — انقر للانتقال) |
| `F` | ملء الشاشة |
| `P` | طباعة / حفظ PDF |
| `H` | إظهار/إخفاء شريط التلميحات |
| سحب على اللمس | تنقّل |

فهرس صفحة 03 قابل للنقر للتنقل بين الفصول، وروابط مباشرة بصيغة `index.html#s5`.

**Background graphics** في حوار الطباعة عند الحاجة.
